## 1. ภาษีหัก ณ ที่จ่าย — `features-wht` (อัดตัวแรก)

**ประโยคเดียวที่คลิปต้องพิสูจน์:** จ่ายเงินครั้งเดียว ได้ 50 ทวิ ที่รวมเงินได้หลายประเภทในใบเดียว และไฟล์ RD Prep โดยไม่คีย์ซ้ำ

**เตรียมข้อมูล:** Payment Journal 1 บรรทัดจ่ายผู้ขายสมมติ (เช่น "บจก. สยามโลจิสติกส์") ที่มีใบแจ้งหนี้ค้าง 2 ใบ ต่างประเภทเงินได้: ค่าขนส่ง 1% และค่าบริการ 3% ยอดกลม ๆ ให้อ่านง่าย เช่น 20,000 + 10,000 · ตั้งค่าให้ WHT คำนวณเองตอน Post

| วิ | เห็นอะไร | ทำอะไร |
|---|---|---|
| 0–1 | Payment Journal บรรทัดเดียว ช่อง Amount ยังเห็นยอดก่อนหัก | นิ่ง |
| 1–2.5 | เปิด Apply Entries ติ๊กใบแจ้งหนี้ 2 ใบ | คลิก Apply → ติ๊ก 2 บรรทัด → OK (เร่ง 1.5×) |
| 2.5–4 | คอลัมน์ WHT Amount ขึ้นยอดเอง (200 + 300 = 500) | หยุด 1 วิ ให้เห็นตัวเลขเปลี่ยน ความเร็วจริง |
| 4–5 | Post → ยืนยัน | คลิก Post → Yes (เร่ง 2×) |
| 5–7 | **ผลลัพธ์:** พรีวิวหนังสือรับรอง 50 ทวิ ซูม 1.6× ที่ตารางประเภทเงินได้ เห็น 2 แถว (ค่าขนส่ง / ค่าบริการ) และยอดรวมภาษีที่หัก 500 | เปิด WHT Certificate → Print/Preview แล้วค้าง |
| 7–8 | ซูมออกเล็กน้อยให้เห็นปุ่ม **Export RD Prep** แล้ว crossfade กลับเฟรม 0 | ถ้าปุ่มอยู่คนละหน้า ตัดสลับภาพ 0.5 วิ ก็พอ |

**ภาพปก:** เฟรมวิ 6 (ตาราง 2 ประเภทเงินได้ในใบเดียว)
**ถ้าต้องตัดให้เหลือ 8 วิ ตัดอะไรก่อน:** ช่วง Apply Entries (วิ 1–2.5) ย่อเหลือภาพ "ติ๊กแล้ว" เฟรมเดียว
**ระวัง:** เลขผู้เสียภาษีผู้ถูกหักต้องเป็นเลขสมมติที่ไม่ผ่าน checksum ก็ได้ ไม่ต้องของจริง · ที่อยู่ในใบใช้ที่อยู่สมมติ

## 2. ภาษีมูลค่าเพิ่ม — `features-vat`

**ประโยคเดียว:** เลือกงวดกับสาขา กดครั้งเดียว ได้รายงานภาษีขายและแบบ ภ.พ.30 ที่กรอกตัวเลขให้แล้ว

**เตรียมข้อมูล:** สำนักงานใหญ่ + สาขา 00001 · ธ.ค. 2569 มีใบกำกับภาษีขาย 5–8 ใบ (มีของสาขาปนอย่างน้อย 2 ใบ) · ยอดภาษีขายรวมกลม ๆ เช่น 35,000

| วิ | เห็นอะไร | ทำอะไร |
|---|---|---|
| 0–1 | หน้า Request Page ของ Sales VAT Report ยังว่าง | นิ่ง |
| 1–3 | กรอกงวด 12/2569 → เลือก Tax Branch = สำนักงานใหญ่ | พิมพ์/เลือกจริง ความเร็วจริง (คนต้องเห็นว่าเลือกสาขาได้) |
| 3–4.5 | Preview รายงานภาษีขาย เลื่อนลงถึงบรรทัดรวม | คลิก Preview → scroll (เร่ง 2×) |
| 4.5–5 | ซูม 1.5× ที่ยอดรวมภาษีขาย 35,000 | ค้าง 0.5 วิ |
| 5–7 | **ผลลัพธ์:** สลับไปแบบ ภ.พ.30 ซูม 1.6× ที่ช่อง 1–7 ที่ตัวเลขถูกกรอกไว้แล้ว เห็นเลข 35,000 ตัวเดียวกันอยู่ในแบบ | เปิดรายงาน ภ.พ.30 งวดเดียวกัน → Preview แล้วค้าง |
| 7–8 | crossfade กลับ | |

**ภาพปก:** เฟรมวิ 6 (ฟอร์ม ภ.พ.30 มีตัวเลข)
**จุดขายที่ต้องไม่หลุด:** ยอดในรายงานกับยอดในแบบต้องเป็นเลขเดียวกันในคลิป คนดูจะจับคู่เอง
**ไม่ต้องใส่:** ภ.พ.36 และ Unrealized VAT (ชิปบนหน้าเว็บพูดแล้ว 8 วิไม่พอ)

## 3. วางบิล — `features-billing`

**ประโยคเดียว:** ปฏิทินบอกเองว่าวันไหนต้องวางบิลใคร ลากเปลี่ยนวันได้ สถานะตามให้

ต่างจาก `hl-billing` (ซึ่งเล่าจาก Board → สร้างใบวางบิล → พิมพ์) คลิปนี้เล่า **ปฏิทินกับการเลื่อนวันอย่างเดียว** ไม่ซ้ำกัน

**เตรียมข้อมูล:** Billing Board ธ.ค. 2569 มีรายการ 3 สีครบ: ถึงกำหนด (วันนี้) 2–3 ราย · เลยกำหนด 1 ราย · ส่งแล้ว 2 ราย · ตั้ง work date เป็นวันกลางเดือน เช่น 15 ธ.ค. 2569

| วิ | เห็นอะไร | ทำอะไร |
|---|---|---|
| 0–1.5 | Billing Board ทั้งเดือน เห็นสีเน้นวันวางบิลและแถบ "เลยกำหนด" สีแดง | นิ่ง (ให้นานกว่าคลิปอื่น 0.5 วิ ปฏิทินมีรายละเอียดเยอะ) |
| 1.5–3 | คลิกวันที่มีรายการ → Worklist ของวันนั้นเปิดขึ้น 3 บรรทัด | คลิกจริง ความเร็วจริง |
| 3–5 | เปลี่ยนวันวางบิลของ 1 บรรทัด จาก 15 → 22 ธ.ค. | แก้ช่อง Billing Date (หรือลากในปฏิทินถ้าทำได้ ลากสวยกว่า) |
| 5–7 | **ผลลัพธ์:** กลับมาที่ Board รายการนั้นย้ายไปอยู่วันที่ 22 สีเปลี่ยนจากแดงเป็นปกติ ซูม 1.5× ที่ช่องวันที่ 22 | ค้าง |
| 7–8 | crossfade กลับ | |

**ภาพปก:** เฟรมวิ 6 (ปฏิทินที่รายการย้ายวันแล้ว)
**ระวัง:** Board เป็นหน้ากว้าง ครอป 4:3 จะตัดข้าง ตอนอัดให้ย่อหน้าต่าง Chrome เหลือ 1600 กว้างพอดีกรอบ ไม่อัดจอเต็มแล้วครอป

## 4. สต็อกและทรัพย์สิน — `features-stock`

**ประโยคเดียว:** Stock Card และทะเบียนทรัพย์สินแบบไทย ออกจากระบบได้เลย ไม่ต้องไปทำใน Excel

คลิปนี้มี 2 ฉาก ต้องตัดต่อ ไม่ใช่เล่นต่อเนื่อง — อัดแยก 2 ไฟล์ก็ได้ (`features-stock-a.mp4`, `features-stock-b.mp4`)

**เตรียมข้อมูล:** สินค้า 1 ตัวที่มีรับ–จ่ายใน ธ.ค. 2569 สัก 6–8 รายการ (ยอดคงเหลือเดินขึ้นลงให้เห็น) · ทรัพย์สิน 3–4 รายการที่ตั้งค่าเสื่อมแล้ว มีค่าเสื่อมสะสมถึงสิ้น ธ.ค.

| วิ | เห็นอะไร | ทำอะไร |
|---|---|---|
| 0–1 | Item Card ของสินค้า | นิ่ง |
| 1–2.5 | เปิด Stock Card report → Preview | คลิก (เร่ง 2×) |
| 2.5–4 | **ผลลัพธ์ที่ 1:** ซูม 1.5× ที่ตาราง รับ / จ่าย / คงเหลือ เห็นคอลัมน์คงเหลือเดินทีละบรรทัด | ค้าง 1.5 วิ |
| 4–4.5 | ตัดภาพ (cut ตรง ๆ ไม่ต้อง fade) ไป Fixed Asset List | |
| 4.5–5.5 | เปิดทะเบียนทรัพย์สิน → Preview | คลิก (เร่ง 2×) |
| 5.5–7 | **ผลลัพธ์ที่ 2:** ซูม 1.6× ที่คอลัมน์ ราคาทุน / ค่าเสื่อมสะสม / มูลค่าสุทธิ ของ 3 แถว | ค้าง |
| 7–8 | crossfade กลับ Item Card | |

**ภาพปก:** เฟรมวิ 6.5 (ทะเบียนทรัพย์สิน) — ผู้สอบบัญชีถามหาตัวนี้มากกว่า Stock Card
**ถ้ายาวเกิน:** ตัด Item Card ออก เริ่มที่ Preview Stock Card เลย

## 5. เอกสารไทย — `features-docs`

**ประโยคเดียว:** ฟอร์มเดียว พิมพ์ได้ทั้งไทยและอังกฤษ และมีครบทุกใบที่ใช้จริง

**เตรียมข้อมูล:** Posted Sales Invoice 1 ใบ ธ.ค. 2569 ลูกค้าสมมติ 3–4 บรรทัดสินค้า · มี Posted Credit Memo และ Billing Note ที่พิมพ์ได้อย่างละ 1 ใบ

| วิ | เห็นอะไร | ทำอะไร |
|---|---|---|
| 0–1 | Posted Sales Invoice | นิ่ง |
| 1–2 | Print → Request Page เห็นช่อง **Language: Thai** | คลิก ความเร็วจริง |
| 2–3.5 | Preview ใบกำกับภาษี/ใบแจ้งหนี้ ภาษาไทย ซูม 1.4× ที่หัวเอกสาร + ตาราง | ค้าง 1 วิ |
| 3.5–4.5 | กลับ Request Page เปลี่ยนเป็น **English** → Preview | คลิก (เร่ง 1.5×) |
| 4.5–5.5 | **ผลลัพธ์:** ใบเดียวกันเป็นอังกฤษ ซูมตำแหน่งเดียวกับวิ 2–3.5 เป๊ะ ให้เห็นว่า layout เหมือนกันทุกเส้น ต่างแค่ภาษา | ค้าง 1 วิ |
| 5.5–7 | พลิกการ์ดเร็ว 0.5 วิ/ใบ: ใบเสร็จรับเงิน → ใบลดหนี้ → ใบวางบิล (ภาษาไทย) | ตัดต่อจากภาพ preview ที่อัดแยกไว้ |
| 7–8 | crossfade กลับ | |

**ภาพปก:** เฟรมวิ 3 (ใบกำกับภาษีไทยซูมที่หัวเอกสาร) ไม่ใช่เวอร์ชันอังกฤษ คนไทยดูหน้าไทย
**อัดแยก:** preview ของใบเสร็จ ใบลดหนี้ ใบวางบิล อัดนิ่ง ๆ ใบละ 3 วิ ไว้ให้ผมตัดใส่ช่วง 5.5–7
**ระวัง:** ใบวางบิลมีเลขบัญชีธนาคารตรงช่องทางชำระเงิน ใช้ของสมมติใน sandbox หรือผมปิดด้วย drawbox เหมือนรอบ Highlight

## 6. API — `features-api`

**ประโยคเดียว:** กดปุ่มเดียว อัตราแลกเปลี่ยนและวันหยุดธนาคารจาก ธปท. เข้าระบบเอง

**เตรียมข้อมูล:** ลบอัตราแลกเปลี่ยนของ ธ.ค. 2569 ออกก่อนอัด ให้ตารางว่างจริง · ปฏิทินวันหยุดปี 2570 ว่าง · ต้องมีเน็ตจริงตอนอัด (ดึงจาก BOT API สด)

| วิ | เห็นอะไร | ทำอะไร |
|---|---|---|
| 0–1 | Currency Exchange Rates ของ USD ตารางว่าง | นิ่ง |
| 1–2 | กดปุ่ม **Get BOT Rates** (ชื่อจริงตามใน JHCore) → เลือกช่วงวันที่ | คลิก ความเร็วจริง |
| 2–4 | ตารางเติมแถวเข้ามา วันละ 1 แถว | ถ้า API ตอบไวเกินไปให้ผมชะลอ 0.7× ตอนตัด คนต้องเห็นแถวทยอยเข้า |
| 4–5 | ซูม 1.5× ที่ 3 แถวล่าง เห็นวันที่ + Relational Exch. Rate | ค้าง |
| 5–7 | **ผลลัพธ์ที่ 2:** ตัดไป Bank Holiday Calendar กดดึง → วันหยุดปี 2570 เรียงเข้ามา ซูม 1.4× ที่ 4–5 แถวแรก (วันขึ้นปีใหม่ มาฆบูชา ...) | คลิก → ค้าง |
| 7–8 | crossfade กลับตารางว่าง | |

**ภาพปก:** เฟรมวิ 4.5 (ตารางอัตราแลกเปลี่ยนที่เต็มแล้ว) — เลข USD/THB คนเข้าใจทันทีโดยไม่ต้องอ่าน
**ระวัง:** ถ้า BOT API ล่มวันที่อัด ไม่ต้องรอ อัดคลิปอื่นก่อน · ค่าอัตราจริงจาก BOT ใช้ได้ ไม่ใช่ข้อมูลลูกค้า
