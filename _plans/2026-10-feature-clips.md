## เป้าหมาย

คนที่เลื่อนมาถึงส่วนไหนต้องเห็นของจริงใน Business Central ในไม่กี่วินาทีโดยไม่ต้องกดอะไร (คลิปแท็บฟังก์ชัน 6–8 วินาที คลิป Highlight 10–12 วินาที)
แบบเดียวกับคลิปโชว์สกิลตัวละครในเกม: เลือกสกิล (แท็บ) แล้วคลิปเล่นเองทันที วนซ้ำ ไม่มีเสียง จบที่ผลลัพธ์ชัด ๆ

คลิปไม่ได้มาแทนเดโมที่กดเล่นได้ ทั้งสองอย่างทำงานคู่กัน: **เดโม = ลองเล่นเอง · คลิป = ดูว่าของจริงหน้าตาเป็นแบบนี้**
บนมือถือ เดโมถูกพับไว้หลังปุ่ม "ดูการนำเสนอ" คลิปจึงเป็นภาพหลักของ section แทน

## โครงคลิปแบบคลิปสกิลในเกม (ใช้กับทุกคลิป)

| จังหวะ | แท็บฟังก์ชัน (8 วิ) | Highlight (12 วิ) | ทำอะไร |
|---|---|---|---|
| ตั้งฉาก | 0–1 | 0–1.5 | หน้าเริ่มต้นนิ่ง ๆ ให้รู้ว่าอยู่หน้าไหน |
| ร่ายสกิล | 1–5 | 1.5–7 | คลิก/พิมพ์จริง ช่วงรอโหลดเร่ง 1.5–2 เท่า เคอร์เซอร์มีวงไฮไลต์ตอนคลิก |
| ผลลัพธ์ | 5–7 | 7–10.5 | ซูมเข้าจุดที่อยากให้จำ (ตัวเลขที่เติมเอง, ฟอร์มไทย, เส้นต้นทุน) ค้างไว้ |
| วนกลับ | 7–8 | 10.5–12 | ซูมออกกลับภาพเริ่ม หรือ crossfade 0.4 วินาที ให้วนต่อเนียน ไม่กระตุก |

**กฎสำคัญกว่าความยาว: ผลลัพธ์ต้องโผล่ภายใน 5–6 วินาทีแรก** คนส่วนใหญ่มองคลิปแวบเดียวแล้วเลื่อนผ่าน จุดเด่นที่มาวินาทีที่ 12 คนจำนวนมากไม่ทันเห็น

- **ไม่มีเสียง** (ยืนยันแล้ว): เบราว์เซอร์ยอมให้เล่นเองเฉพาะวิดีโอที่ปิดเสียง และเสียงที่ดังเองตอนเลื่อนหน้าทำให้คนปิดแท็บ · อยากมีเสียงบรรยายเมื่อไร แยกทำคลิปยาว 1–2 นาทีลง YouTube แล้วลิงก์ "ดูคลิปเต็มพร้อมเสียง"
- ไม่ใส่ตัวหนังสือทับในคลิป (หน้าเว็บมีคำอธิบายอยู่แล้ว และคลิปเดียวใช้ได้ทั้ง TH/EN)
- UI ของ BC เป็นภาษาอังกฤษ ข้อมูลเป็นภาษาไทย ให้ตรงกับเดโมบนหน้าเว็บ

## วิธีอัด (พี่ซันทำ)

1. **ข้อมูล:** ใช้ sandbox บริษัทตัวอย่าง ตั้งข้อมูลให้ตรงกับเดโมบนเว็บถ้าทำได้ (โรงงานถุงมือของ Cost Trace, กลุ่มลูกค้าวางบิล)
   - ห้ามมีข้อมูลลูกค้าจริง ชื่อ tenant อีเมลผู้ใช้ ตัวย่อชื่อมุมขวาบนของ BC
   - VAT Service ต้องใช้เลขผู้เสียภาษีที่มีอยู่จริง ใช้เลขของ JWIC เองหรือบริษัทมหาชนที่ข้อมูลเปิดเผยอยู่แล้ว ไม่ใช้เลขลูกค้า
2. **หน้าจอ:** Chrome หน้าต่าง Guest ปิดแถบ bookmark ซูม 100% ปิดแจ้งเตือน Windows
   - คลิป 4:3 อัดกรอบ 1600×1200 · คลิป 16:9 อัดกรอบ 1920×1080 (ใหญ่กว่าที่ส่งออก ซูมทีหลังได้ไม่แตก)
3. **เครื่องมือ (ฟรีบน Windows):** OBS Studio อัดแบบเลือกกรอบ · PowerToys Mouse Highlighter ทำวงตอนคลิก
   - **อัด 120 fps** (หารลงตัวกับ 30 fps ของเว็บ ช่วงที่เร่ง 2 เท่ายังลื่น) · ไม่ใช้ 144 เพราะ 144 ÷ 30 ไม่ลงตัว เมาส์จะกระตุกเป็นจังหวะ
   - จอ 144Hz: ปรับเป็น 120Hz ระหว่างอัด (Settings → Display → Advanced display → Refresh rate)
   - OBS → Video: FPS Type = Integer FPS Value = 120 · Output (Advanced): encoder ของการ์ดจอ (NVENC/AMF) ไม่ใช้ x264 · CQP 18–20 · บันทึกเป็น MKV แล้ว File → Remux Recordings เป็น MP4
   - Stats ขึ้น skipped frames เมื่อไร ลดเหลือ 60 fps ได้เลย ผลบนเว็บแทบไม่ต่าง
   - อยากซูมนุ่มแบบเกม: ตัดใน CapCut Desktop หรือ DaVinci Resolve
   - ไม่ตัดก็ได้ ส่งไฟล์ดิบมา ผมตัด เร่ง และซูมด้วย ffmpeg ให้
4. **ไฟล์ดิบ:** ยาวได้ 30–60 วินาทีต่อคลิป ตั้งชื่อตามช่อง เช่น `features-vat.mp4`, `hl-billing.mp4`
   - วางใน `video/raw/` (gitignore ไว้ ไม่ขึ้นเว็บ)
   - session บนคลาวด์มองไม่เห็นไฟล์ในเครื่อง ให้เรียก Claude Code ในเครื่องทำขั้นต่อไป หรือแนบไฟล์ที่ตัดแล้วในแชต
   - ไฟล์ดิบ 120 fps ใหญ่ราว 2 เท่าของ 60 fps (คลิป 1 นาทีอาจหลายร้อย MB) แนบในแชตให้ตัดเหลือช่วงที่ใช้ก่อน

## สเปกไฟล์และการเข้ารหัส (ผมทำ)

- โฟลเดอร์ใหม่ `video/` (เพิ่มแถวในตารางโครงไฟล์ของ CLAUDE.md ตอนทำจริง): `video/<ช่อง>.mp4` + ภาพปก `video/<ช่อง>.webp` (เฟรมผลลัพธ์ที่ซูมแล้ว — คนที่ไม่เล่นคลิปเห็นแค่ภาพนี้)
- MP4 H.264 `yuv420p` + `faststart` · 30fps · **ไม่มี track เสียง** · ไม่ทำ WebM: คลิปจอ BC ที่ VP9 crf 36 ได้ 860KB ใหญ่กว่า MP4 (593KB) ต้องบีบถึง crf 46 ถึงเล็กกว่า 15% แลกกับตัวหนังสือเบลอ
- ได้จริง: `hl-vat` 10.9 วิ 593KB · `hl-billing` 11.9 วิ 410KB · `hl-cost` 9.2 วิ 388KB
- **กรอบครอป:** เริ่มที่ตัวหน้า BC (x ≥ 96–100 ที่ 1920×1080) ไม่เอาขอบเทานอกหน้า ปุ่ม "←" ย้อนกลับ และปุ่ม "‹" เลื่อนระเบียน (ผู้ใช้เห็นแถบเทาในคลิป VAT ตอนเต็มจอ) · คลิปที่กว้างเกิน 16:9 (กราฟ Cost Trace 145%) ใช้เติมขอบขาวบนล่างแทนการตัดข้าง
- ขนาดเป้า (ราว 90KB ต่อวินาทีที่ 720p): คลิปแท็บฟังก์ชัน 8 วิ ไม่เกิน 0.8MB · คลิป Highlight 12 วิ ไม่เกิน 1.2MB · รวม 9 คลิปไม่เกิน 9MB
- เบราว์เซอร์โหลดเฉพาะคลิปที่กำลังจะเล่น ไม่โหลดทั้ง 9 ตัวตอนเปิดหน้า

```bash
# ตัดช่วง 3–21 วิ เร่ง 1.5 เท่า (ได้ 12 วิ) ย่อเป็น 1280×720 · ต้นฉบับ 120fps → fps=30 หยิบทุกเฟรมที่ 4 สม่ำเสมอ · ไม่มีเสียง
ffmpeg -ss 3 -to 21 -i video/raw/hl-billing.mp4 -an \
  -vf "setpts=PTS/1.5,scale=1280:720:flags=lanczos,fps=30" \
  -c:v libx264 -crf 26 -preset slow -pix_fmt yuv420p -movflags +faststart video/hl-billing.mp4
# ภาพปก = เฟรมผลลัพธ์ (ช่วงที่ซูมค้างไว้)
ffmpeg -ss 7.6 -i video/hl-billing.mp4 -frames:v 1 -c:v libwebp -quality 80 video/hl-billing.webp
# ซูมเข้าช่วงผลลัพธ์ (ตัวอย่าง: วิ 7–10.5 ซูม 1.6 เท่าที่มุมขวาล่าง) ใช้ zoompan หรือ crop+scale ทีละช่วง แล้ว concat
```

## โค้ดบนหน้า (ผมทำ)

```html
<div class="clip" data-clip="billing-flow">
  <video muted loop playsinline preload="none" width="1280" height="720" poster="video/hl-billing.webp" aria-hidden="true">
    <source src="video/hl-billing.mp4" type="video/mp4">
  </video>
</div>
```

- **ปุ่มสคริปต์สร้างเอง** (แถบ `.clip-ctrl` ใต้คลิป: ▶/❚❚ + ⤢) — HTML เหลือแค่ `<video>` ไม่มี JS ก็เห็นภาพปก ไม่มีปุ่มที่กดไม่ได้ · ป้ายปุ่มมีชื่อ section เช่น "เล่นคลิป ระบบวางบิล" ปุ่มหลายชุดจะได้ไม่ชื่อซ้ำ
- **ขยายเต็มจอ:** ปุ่ม ⤢ หรือคลิกที่ตัวคลิป → `requestFullscreen()` ที่ `.clip` แล้วเล่นทันที · Safari ก่อน 16.4 ใช้แบบ webkit (เช็กสถานะด้วย `webkitFullscreenElement` ด้วย) · iPhone ขยายได้เฉพาะ `<video>` จึงตกไปใช้ `webkitEnterFullscreen()` ห่อ try/catch แล้วลองซ้ำตอน `loadedmetadata` (ยังไม่ได้ลองบนเครื่องจริง)

- **ไม่ใส่ `autoplay` ใน HTML:** สคริปต์สั่งเล่นเองเมื่อคลิปโผล่บนจอเกินครึ่ง (IntersectionObserver) และหยุดเมื่อเหลือไม่ถึงครึ่ง
  - ดู `intersectionRatio` ไม่ใช่ `isIntersecting` — ตอนเหลือไม่ถึงครึ่ง `isIntersecting` ยังเป็น true
  - หน่วง 300ms ก่อนเล่น: กดเมนูแล้ว smooth scroll ผ่าน จะไม่เริ่มโหลดคลิป
  - เลิกเล่นเองเฉพาะ `NotAllowedError` — `AbortError` (pause ตัดกลางตอนโหลด) ไม่นับ ไม่งั้นคลิปที่เลื่อนผ่านตอนเน็ตช้าจะไม่เล่นเองอีกเลย
  - ส่วนฟังก์ชันเล่นเฉพาะแท็บที่เปิด และรีสตาร์ตทุกครั้งที่เปลี่ยนแท็บ
- **ไม่เล่นเอง ให้โชว์ภาพปกพร้อมปุ่ม ▶ แทน เมื่อ:** ผู้ใช้ตั้ง `prefers-reduced-motion: reduce`, เปิดโหมดประหยัดเน็ต (`Save-Data`) หรือเบราว์เซอร์ปฏิเสธการเล่นเอง (iPhone โหมดประหยัดแบต)
- **ไม่ให้หน้ากระโดด:** ใส่ `width`/`height` และ `aspect-ratio` ทุกตัว
- **I18N:** ป้ายปุ่มเปลี่ยนตามสถานะ จึงสลับภาษาในสคริปต์ของมันเอง (`window.syncClips` เรียกจาก `applyLang`) ไม่ผ่าน `I18N_ATTR`
- **CSP:** `default-src 'self'` อนุญาตวิดีโอจากโดเมนเดียวกันอยู่แล้ว ไม่ต้องแก้ · ถ้าวันหน้าย้ายไป YouTube/Cloudflare Stream ต้องเพิ่ม `media-src`
- **GA:** event `clip_play` (ชื่อช่อง) ครั้งแรกที่คลิปเล่น จะได้รู้ว่าคนดูคลิปไหน · `clip_fullscreen` ทุกครั้งที่กดขยาย
- **DESIGN.md:** เพิ่ม component "Clip" (สัดส่วน, กรอบ, แถบใต้คลิป, กฎไม่เล่นเองตาม reduced-motion)

## ผลต่อ CI และหน้ามือถือ

- `page-checks` เพดานความยาวหน้ามือถือ 21,000px · ก่อนเริ่ม 16,335px · หลังใส่ Highlight 3 คลิป + นิยามใบวางบิล 17,743px (TH) / 18,224px (EN) · พิมพ์ A4 ยัง 4 หน้า
  - แท็บฟังก์ชันรอบสองจะสูงขึ้นอีกราว 60px ยังห่างเพดานมาก
- ไม่มีไฟล์ใหญ่: GitHub Pages รับไฟล์ละไม่เกิน 100MB และทั้งเว็บไม่เกิน 1GB คลิปทั้งหมดราว 9MB
- เพิ่มกฎใน `page-checks.mjs`: ทุก `<video>` ต้อง `muted` + `playsinline` + มี `poster` และไม่มี `autoplay` ใน HTML

## ลำดับงาน

1. พี่ซันอัด **Highlight 3 คลิปก่อน** (คนเห็นเยอะสุด และบนมือถือเป็นภาพหลักของ section)
2. ผมตัด/บีบ/ทำภาพปก → ใส่หน้าเว็บ → แคปเทียบก่อน/หลัง + CI → ship
3. ทดสอบบนเครื่องจริง: iPhone Safari (ทั้งปกติและโหมดประหยัดแบต), Android Chrome (Data Saver), Windows Chrome/Edge
4. รอบสอง: อัด 6 คลิปของส่วนฟังก์ชัน → ปรับกรอบเป็น 4:3 → ship

## ข้อควรระวัง

- **BC เปลี่ยนหน้าตา คลิปก็ต้องอัดใหม่:** เช่น Cost Trace เพิ่งเปลี่ยนเป็นบล็อกในกล่องเมื่อ 3 ต.ค.

  - คลิปไม่ใช่ลิงก์ที่แชร์ออกไป เปลี่ยนเนื้อได้ แต่อย่าเปลี่ยนชื่อไฟล์ ภาพปก og/เด็คอาจอ้างอยู่
- **ความเร็วต้องอ่านทัน:** เร่งได้เฉพาะช่วงรอ ช่วงที่ตัวเลขหรือฟอร์มไทยโผล่ต้องเป็นความเร็วจริงหรือช้ากว่า
- **ตรวจข้อมูลก่อนส่ง:** เปิดดูทุกเฟรมว่าไม่มีชื่อลูกค้าจริง อีเมล หรือ URL ของ tenant หลุดมา
  - ไฟล์ดิบรอบแรกติดแถบ Chrome มาทั้งหมด (URL Tailscale, bookmark ชื่อ MIELE/Odoo) และแถบหัว BC (ป้าย JHTEST, ตัวย่อ S) — ครอปทิ้งทุกคลิป
  - ใบวางบิลมี **เลขบัญชีธนาคาร + ชื่อเจ้าของบัญชี** ที่ช่องทางชำระเงิน — ปิดด้วย `drawbox` สีขาวก่อนครอป (เลขผู้เสียภาษีของ JWIC อยู่บนเว็บอยู่แล้ว ไม่ต้องปิด)
