# voice/

บทพูดไทยสำหรับคลิปประกอบ presales + เครื่องมือตรวจงาน

## สถานะ: เลิกทำ TTS ในเครื่องแล้ว (2026-08-15) — ย้ายไปใช้บริการเสียเงิน

ทดสอบ TTS ที่รันเองในเครื่อง 3 ตัว **ตัดทิ้งหมด** คุณภาพเสียงไม่ถึงระดับที่เอาไปใช้งานจริงได้:

| ตัว | ทำไมถึงตัด |
|---|---|
| Microsoft edge-tts | สำเนียงเหน่อ |
| ThonburianTTS (F5-TTS ไทย) | รวบประโยคยาว + โมเดล CC BY-NC-SA ใช้เชิงพาณิชย์ไม่ได้ |
| OmniVoice (k2-fsa) | ประโยคไล่รายการเข้าลูปพ่นคำซ้ำ สำเนียงยังไม่ผ่าน |

ตัวเลือกที่เสียเงิน (ยังไม่ได้เลือก): **Botnoi Voice** (เริ่ม 99 บาท เสียงไทยแท้),
**ElevenLabs Starter** ($5/เดือน โคลนเสียงตัวเองได้ มีสิทธิ์เชิงพาณิชย์ — ตัวฟรีห้ามใช้เชิงพาณิชย์),
หรืออัดเสียงตัวเอง

## ของที่เก็บไว้ใช้ต่อ (ใช้ได้กับ TTS ทุกเจ้า)

| ที่ | อะไร |
|---|---|
| `tts-test-script.txt` | บททดสอบยาว เรื่องย้ายโปรแกรมบัญชี มีตัวเลขเงิน วันที่ไทย ศัพท์ ERP ครบ ไว้ลองของใหม่ |
| `tts-test-script-thai.txt` | บทเดียวกัน แต่**สะกดศัพท์อังกฤษเป็นคำอ่านไทย** — ใช้เป็นคู่มือคำอ่านศัพท์ ERP |
| `verify-tts.py` | ถอดเสียงกลับเป็นข้อความด้วย Whisper ไทย เช็คว่าอ่านครบไหม |
| `edge-tts/` | โฟลเดอร์ทดลองเดิม (เลิกใช้แล้ว) |

## กฎการเขียนบทให้ TTS อ่านรู้เรื่อง

เรียนรู้จากการทดสอบ OmniVoice แต่น่าจะใช้ได้กับเจ้าอื่นด้วย ลองแล้วค่อยปรับ:

**1. อย่าไล่รายการเปล่า ๆ ให้มีคำไทยคั่นทุกตัว** — ตัวจุดชนวนไม่ใช่ประโยคยาวหรือชื่อเยอะ
แต่คือลิสต์ที่คั่นด้วยจุลภาคล้วน ๆ ชื่อโมดูลชุดเดียวกันเป๊ะ เขียนสองแบบได้ผลคนละเรื่อง:

```
❌ โมดูลหลักมี A, B, C, D และ E                                    -> พัง 8 ใน 10 รอบ
✅ โมดูลหลักมี A สำหรับงานบัญชี ต่อด้วย B ฝั่งขาย แล้วก็ C ฝั่งจัดซื้อ
   ส่วนงานสต๊อกใช้ D คู่กับ E                                      -> ผ่าน 3 ใน 3 รอบ
```

ประโยคที่มีชื่อโมดูลถึง 8 ตัวแต่มีคำไทยคั่น ไม่พังสักรอบ — **เขียนให้เหมือนคนพูดจริง ไม่ใช่อ่านบูลเล็ตในสไลด์**

**2. ศัพท์อังกฤษเขียนเป็นคำอ่านไทย** — `Purchase and Payables` เขียนตรง ๆ อ่านออกมาเป็น "ปล่อย และ ปล่อย"
แต่เขียน `เพอร์เชส แอนด์ เพเยเบิลส์` อ่านถูก (คำอ่านศัพท์ ERP ทั้งชุดอยู่ใน `tts-test-script-thai.txt`)

**3. ตรวจงานทุกไฟล์ อย่าเชื่อว่าอ่านครบ** — เสียงที่พังเป็นเสียงมั่ว ไม่ใช่เงียบ ดูจาก waveform ไม่ออกเลย
(peak กับสัดส่วนความเงียบปกติทุกไฟล์) ต้องถอดกลับเป็นข้อความเท่านั้นถึงจะจับได้:

```
d:\JHLinkedin\.venv\Scripts\python.exe verify-tts.py เสียง.wav
```
