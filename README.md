# JHPresales

Workspace สำหรับทำ PowerPoint presales และเตรียม present

## โครงสร้าง
- `decks/` — ไฟล์ .pptx ที่ส่งจริง (ตั้งชื่อ `YYYY-MM-DD-ลูกค้า-หัวข้อ.pptx`)
- `outline/` — ร่าง outline / สคริปต์พูด ก่อนลง PowerPoint
