## หมายเหตุ

- **ข้อความไทยที่ลงไฟล์ให้เรียก `jhthai` ก่อนทุกครั้ง** — หน้าเว็บ บทความ สคริปต์เด็ค และเอกสารที่ลูกค้าอ่าน
  รีวิวก็ใช้กฎชุดเดียวกัน อ่านสกิลแล้วแก้ตามที่เจอในรอบเดียว · ภาษาไทยที่ตอบในแชต ข้อความ commit
  และ label บนจอ **ไม่ต้องเรียก** (สกิล `kode-thai` ที่วน audit→fix ลบทิ้ง 20 ก.ย. 2026)
- **`jhthai` ย้ายไปอยู่ระดับ user แล้ว** (`~/.claude/skills/jhthai` ตั้งแต่ 21 ต.ค. 2026 ชุดเดียวใช้ทุก repo) — กฎของเว็บนี้อยู่ใน
  `references/house-site.md` ของมัน กฎที่ใช้ร่วมกันอยู่ใน `SKILL.md` · ที่มา (chakrit/kien-thai, MIT) และที่แก้จากต้นฉบับอยู่ใน `VENDORED.md`
  ของมัน · สำเนาเดิมในโฟลเดอร์นี้ดูได้จากประวัติ git
- ปรับแก้ไฟล์ในโฟลเดอร์นี้ได้ตามใจ — เป็นสำเนา ไม่ได้ผูก submodule กับต้นทาง (แลกกับว่าไม่ได้อัปเดตตามเขาเอง)
